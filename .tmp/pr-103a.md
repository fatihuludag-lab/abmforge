\## Summary



Introduce the first building block for experiment recovery.



This PR adds deterministic recovery utilities that compare planned

scenarios against archived completed runs without modifying experiment

execution.



\## Added



\- RunKey deterministic identity

\- completed\_run\_keys()

\- missing\_scenarios()

\- recovery module

\- public recovery API exports



\## Behaviour



\- completed runs are skipped

\- failed runs remain runnable

\- parameter ordering does not affect matching

\- duplicate planned runs are handled correctly



\## Tests



Added regression tests covering:



\- completed run filtering

\- parameter ordering

\- failed reruns

\- duplicate planned scenarios

\- empty archive

\- empty experiment plan

all passing.
